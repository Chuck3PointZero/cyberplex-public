Signing in

1

Enter your name and owner email

Press Send sign-in code. There is no password.

2

Type the eight-digit code from the email

Press Verify email. No email? Use Request a new code.

3

Choose your tenant

It appears in the Tenant box. You stay signed in for up to 7 days.

The ten-minute rule. Approving a request or verifying an agent needs a code from the last ten minutes. If the page asks you to verify again, do it, then reopen the record and review it again. It will not repeat your click for you.

The workspace page

Sign-in is by emailed code, no password. An API key does not sign you in: keys are for agents, the code is for people. The part that surprises everyone is the ten-minute rule. Reading is fine for the whole week you stay signed in, but anything that carries your authority, like approving a decision, needs a fresh code. When that happens the page asks you to verify, and afterwards you have to open the request again and press the button again. That is deliberate: it will not replay a decision you made before you were verified.
