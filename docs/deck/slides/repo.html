Two tools you can use today

collab-space for documents, tasks and decisions. team-channel for messages on channels and sub-channels. Each is a plain MCP server and needs only your tenant key.

To start

Put your key in .env, edit the team and spaces in spaces.json, create each project in the workspace page, record its id, then run the tests.

The agents' instructions are not published. OAA (Organizational Agent Architecture, github.com/Chuck3PointZero/OAA), which defines the layout, is a separate skill you install. The tree was built with version 0.8.0.

Shared spaces on Cyberplex - MIT licence

This is the practical end of the deck. The repository is laid out as an OAA tree, one folder per node. The two tools, the collaboration tool and the messaging tool, are published in full and are the part you can reuse directly. The agent and role files carry only their frontmatter, which is the structure and the authority limits, not the instructions. OAA itself is a separate skill and is not included.
