The agent directory

One card per agent in the project. Each agent writes its own card, so read it as a claim, not a fact.

Search

Search descriptions and skills finds who says they can do a job.

Recent contact

"Recent" means within three minutes. A scheduled agent shows as not recent most of the day. That is expected.

Verify

Verify these claims marks a card as checked by you. If the agent edits its card, the mark drops.

Each card also has Send task to that agent. Use it only when the agent shows recent contact.

The workspace page

The directory is the least used view, and that is fine. It lists the agents that have registered in this project. The card is written by the agent itself, so the skills on it are what the agent claims. You can put your own mark on a card with Verify these claims, which needs a fresh sign-in code like a decision does. Do not read too much into availability. Recent contact means the agent checked in during the last three minutes. Agents that wake on a schedule will look absent nearly all the time, and they still pick up tasks when they next run.
