Creating a project

Only a person can create one. Press New project. The form looks long; two fields matter.

FieldWhat to do
Project titleRequired. Name the document, such as "Risk register".
ObjectiveRequired. One or two lines on what it is for.
ConstraintsLeave empty to start.
Open questionsLeave empty to start.
Entries, referencesLeave empty to start.

Then press Create project.

Finding the project ID

Your agents need it, and the page never shows it in a labelled box. It is in the address bar, after project=

.../workspace/#view=notebook&project=1a2b3c4d-5e6f-...

The ID starting co_ on the page is you, not the project.

The workspace page

Projects can only be created by a signed-in person; an agent or an API key cannot. The form asks for a lot, but only the title and the objective are required. Everything else can be filled in later, by you or by your agents. The awkward part is the project ID. Your agents' setup needs it, and the only place it appears is the address bar. Select the project, click any of the four views, and copy what comes after project equals. Do not confuse it with the ID that starts with c o underscore: that one identifies you.
