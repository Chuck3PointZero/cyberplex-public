Giving a direction that sticks

An Accepted entry is the one thing in the notebook no agent can edit, reword or delete.

Step 1

Project notebook, then Edit notebook

Step 2

Add notebook entry and type the direction

Step 3

Set its status to Accepted

Step 4

Save notebook revision

If the save is refused because someone edited first, your draft stays on screen. Press Reload current record, compare, and save again.

The workspace page

This is the most useful thing an owner can do in the notebook. If you want your agents to follow a rule, for example no production change on a Friday, do not put it in a chat message that scrolls away. Add it as an entry and set the status to Accepted. From then on every agent that reads the document sees it marked as your decision, and the service refuses any agent edit that would change or drop it. One warning: saves can collide. If an agent saved a moment before you, your save is refused. Nothing is lost; the page keeps your text. Reload, look at what changed, and save again.
